# Эхо — клон Discord

Самостоятельное веб-приложение для портфолио: серверы (гильдии), текстовые каналы, личные сообщения, статусы «в сети», индикатор «печатает…» и голосовые комнаты с базовым голосом через WebRTC mesh.

## Возможности

- Серверы с кодом приглашения (буква на круге в левой панели, вход по коду).
- Текстовые и голосовые каналы; создание каналов всем участникам, удаление — только владельцу сервера.
- Лента сообщений: аватар-буква, имя, время, пометка «(изменено)», правка и удаление своих сообщений, подгрузка истории вверх («Загрузить ещё», окно ~100 сообщений).
- Личные сообщения: отдельная вкладка со списком диалогов; диалог открывается кликом по участнику в правой колонке.
- Presence: зелёная точка у «в сети», участники онлайн первыми; обновляется через WebSocket.
- Индикатор «X печатает…» под лентой (4 секунды после последнего события).
- Голосовые комнаты: список сидящих под каналом, кнопка «Зайти в голос», WebRTC mesh (каждый участник соединяется с остальными напрямую), мьют микрофона через WebAudio, выход из комнаты. Не в защищённом контексте (не https) голос недоступен — показывается уведомление и только список сидящих.
- Всё на русском, тёмная тема, без эмодзи и всплывающих window.alert — свои тосты и модальные окна.

## Стек

- Node.js 24, чистый ESM, без TypeScript и без сборки.
- `better-sqlite3` — SQLite (файл `data/app.db`, WAL, foreign keys, миграции).
- `ws` — WebSocket.
- WebRTC (нативный API браузера) для голоса, STUN Google.
- Статика и мини-роутер — из общего каркаса `lib/` (http.mjs, db.mjs, auth.mjs, ws.mjs, util.mjs).

## Запуск

```
npm install
npm start          # порт 3011, переменную можно переопределить: PORT=8080 npm start
```

Открыть http://localhost:3011 — вход по имени (демо-режим, без паролей). `localhost` считается защищённым контекстом, поэтому голос работает и без https; для доступа с других машин по IP нужен https, иначе будет уведомление «Голос работает только по https-ссылке».

При первом запуске с пустой БД создаётся сид: сервер «Основной» (код приглашения `DEMO`), каналы «общий» и «мемы» (текстовые), «Комната 1» и «Комната 2» (голосовые) и пара сообщений от пользователя-заготовки.

## API (REST, куки-сессия)

| Метод и путь | Назначение |
|---|---|
| `POST /api/login {name}` | вход/регистрация по имени |
| `POST /api/logout` | выход |
| `GET /api/me` | текущий пользователь |
| `POST /api/servers {name}` | создать сервер (+ каналы «общий» и «Голосовая») |
| `POST /api/servers/join {code}` | войти по коду приглашения |
| `GET /api/servers` | мои серверы |
| `GET /api/servers/:id` | сервер: каналы (у голосовых — occupancy) + участники (online) |
| `POST /api/servers/:id/channels {name, kind}` | создать канал (`text`/`voice`) |
| `DELETE /api/channels/:id` | удалить канал (только владелец сервера) |
| `GET /api/channels/:id/messages?before=<ts>&limit=50` | окно истории для подгрузки вверх |
| `POST /api/channels/:id/messages {text ≤ 2000}` | отправить сообщение |
| `PATCH /api/messages/:id` | изменить своё сообщение |
| `DELETE /api/messages/:id` | удалить своё сообщение |
| `POST /api/channels/:id/typing` | «печатает…» |
| `GET /api/dm` | список диалогов |
| `GET /api/dm/:userId/messages?before=&limit=` | история диалога |
| `POST /api/dm/:userId {text}` | отправить в ЛС |

## WebSocket `/ws`

Подключение требует куки сессии. Клиент раз в 25 секунд шлёт `heartbeat`. Сервер держит набор «онлайн» и рассылает `presence`.

События сервер → клиент: `presence`, `message:new`, `message:edit`, `message:delete`, `dm:new`, `typing {channelId, userName, until}`, `voice:join / voice:leave {channelId, userId, userName, occupants}`, `voice:signal {from, data}` (релеинг WebRTC-сигналинга), `heartbeat` (эхо).

События клиент → сервер: `heartbeat`, `voice:join {channelId}`, `voice:leave`, `voice:signal {to, data}`.

Голос: зашедший в комнату получает список сидящих и сам делает offer каждому (mesh), дальше обмен ICE/SDP через `voice:signal`.

## Самопроверка

```
node scripts/ws-smoke.mjs    # при запущенном сервере: REST 401, broadcast, typing, voice, presence, heartbeat
```

## Ограничения

- Демо-авторизация: вход по имени без пароля, любой, кто знает имя, может войти под ним.
- Голос — mesh без TURN-сервера: за симметричным NAT соединение может не установиться.
- Сообщения без вложений и markdown, лимит 2000 символов.
- Occupancy голосовых, typing и онлайн — в памяти сервера и не переживают рестарт.
